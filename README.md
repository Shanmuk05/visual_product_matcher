# 🔎 Visual Product Matcher

Upload or paste a product image and this app finds the most visually similar
items in the catalog using **OpenAI CLIP** (ViT-B/32) image embeddings and
cosine similarity. Built with Streamlit.

Catalog of 44 products with precomputed CLIP feature vectors.
